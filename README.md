# freeCodeCamp – Full-Stack Curriculum (Progress & Solutions)

This directory contains my structured solutions for the **Labs**, **Workshops**, and **Certification Projects** from the [freeCodeCamp](https://freecodecamp.org) curriculum. All exercises are developed, debugged, and version-controlled locally in **VS Code**.

## Directory Structure

- `Labs/` – Independent coding challenges, data algorithms, and logic implementations
- `Workshops/` – Guided hands-on projects (DOM manipulation, UI components, event handling)
- `practice/` – Custom experiments, code refactoring, and technical notes
